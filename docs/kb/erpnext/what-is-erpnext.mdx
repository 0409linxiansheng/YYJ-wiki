有人问我 ERPNext 是啥，我一般这么答：**就是一套免费的公司管理系统。**

销售的单子、采购的记录、仓库还剩多少货、谁欠我多少钱、员工考勤 —— 这些事平时要么散在 Excel 里，要么散在微信里，要么只存在某个人的脑子里。ERPNext 干的事，就是把它们收进一个地方，而且互相通着。

举个最常见的场景：你卖出去一单。

库存自动减了，发货单自动出来了，财务那边应收款也有了。不用你再跑到三个表里改三遍。

就这么点事，但省下来的时间是真金白银。

## 它到底解决什么问题

小公司的日常，基本上是这样的：

- 客户资料在销售自己的微信里
- 订单一单一单记在 Excel
- 库存靠另一个人记着，或者靠感觉
- 月底财务追着要数据，大家凑半天，还对不上

这真不是谁不认真，是数据本来就是散的。

上了系统之后，同一个东西只录一次，后面的都自己算。所以 ERP 真正的价值，说白了就一句：**少抄几遍，少对几次账。**

## "免费开源"这四个字，坑不少

这是新手最容易误解的地方，我觉得有必要说清楚。

**软件本身确实不要钱。** 代码是公开的，你可以自己下载、自己装，不像很多商业 ERP 那样按人头收授权费。

但下面这几样是要花钱的：

- **服务器**：得有台机器一直开着，云服务器最省事
- **时间**：装软件不难，难的是"你公司的流程怎么塞进系统"，这块最费精力
- **改功能**：它没有的东西，要么将就，要么花钱改代码

所以我一般跟人说：**ERPNext 省的是软件钱，不省人力钱。** 预算得按"服务器 + 人"来算，不能只看"软件免费"。

## 里头都有啥

大致这么几大块：

- **销售 / 客户**：客户档案、报价、订单、跟进记录
- **采购**：供应商、采购单、到货
- **库存**：进出库、调拨、盘点
- **财务**：应收应付、总账、报表
- **项目**：项目、任务、工时
- **人事**：员工、考勤、工资
- **制造**：BOM、生产计划（做工厂的才用得上）

好处是这些都在一个系统里，不用买五六个软件再想办法拼起来。

但有一句得提醒：**别一上来全开。**

模块是可以只装一部分的。小公司通常先跑「销售 + 采购 + 库存」，等财务报表能顺出来了，再想人力、制造这些。一次性全开，大概率最后谁都不用。

## 什么人用得上，什么人用不上

**大概率用得上：**

- 有实物流转的：贸易、批发、零售、小工厂
- 现在靠 Excel 加微信管业务，数据老是对不上
- 有人愿意花点时间把流程理一遍（这条最要紧）

**大概率先别碰：**

- 店很小、业务也单一，比如就卖几样固定商品、一个人管进销存 —— 先用表格把账理顺更划算，等单量上来了或者要同时对接线上线下几个渠道再说
- 想"装上就自动变规范"的 —— 系统不会替你决定流程，它只会把混乱放大
- 完全没人懂电脑、又不想花钱请人做实施的 —— 后面维护会很难受

## 我为什么会碰这个东西

最早不是我自己要用，是朋友找我。

他做批发生意，公司不大，客户和订单一直靠 Excel 加微信记。麻烦不在于"记不下来"，而在于"记得不齐"：销售改过的价格财务不知道，仓库发出去的货跟单子对不上，到了月底一核对，就得加班好几天。

他也想过买现成的 ERP，问了几家，报价按人数算，一年下来不便宜；功能倒是齐全，可大半他用不上。

我当时的想法特简单：先把他最头疼的三件事 —— 客户、订单、库存 —— 放进一个系统里，别的以后再说。ERPNext 免费开源、能装在自己服务器上、要改也改得动，条件刚好对得上。

结果真上手才发现，难的根本不是软件，是"把他脑子里那套流程讲清楚"。这事儿我后面单独写一篇。

后来陆陆续续又帮几个做贸易的朋友搭过，踩的坑都差不多：系统装得起来，但用不起来。

## 想开始的话，三句实话

1. **先画流程，再装软件。** 拿张纸把"客户下单 → 备货 → 发货 → 收款"写一遍，比装软件重要得多
2. **数据先整理。** 客户名单、商品清单先弄成规整的表格，后面导入能少受一半罪
3. **别贪多。** 先跑一条业务线，跑顺了再加，一上来全铺开基本都会烂尾

## 最后

ERPNext 不是"高级版 Excel"。它更像一套**要求你先想清楚流程**的系统：想清楚了很好用，没想清楚，装完也只是多一个没人打开的网页。
