# 关于云屿集

云屿集是一个个人知识站点：把业务里的判断、行业里的理解，整理成可以回看和复用的内容。

## 这里有什么

- **业务分享**：项目复盘、方法论、真实场景里的取舍
- **行业知识**：术语、政策、案例，以及行业里的常识
- **工具资源**：我自己在用的工具、模板和配置

## 为什么叫「云屿集」

云是流动的，屿是落脚的地方。业务一直在变，但每一次沉淀下来的判断，都该有一个可以回看的岛。

## 关于我

这里替换成你的介绍：所在行业、做过什么、正在关注什么。
