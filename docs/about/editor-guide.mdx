## 打开

- 地址：`http://192.168.1.102:3002/app/`（只有局域网能开）
- 密码：自己设的那个；忘了在服务器上执行 `rm ~/sites/my-website/editor/settings.json && systemctl --user restart yyj-editor` 重设

## 写一篇新文章

1. 左侧选好分类（知识库 → ERPNext 等）
2. 点底部「+ 知识库文章」或「+ 技术手记」
3. 填标题 → 进入编辑
4. 正文里直接打字；打 `/` 可以插入组件（提示框 / 折叠块 / 卡片 / 步骤条 / 标签页 / 视频）
5. 拖图片进正文会自动上传
6. 点「保存」（只写文件）→ 点「发布」（提交并推送到 GitHub）

## 双链与预览

- 右侧「🔗 链接文章」→ 选一篇文章 → 插入 `[[路径|标题]]`
- 只有这种双链才有**鼠标悬停预览**；普通链接不会预览
- 被引用的页面底部会自动出现「引用这篇的文章」

## 分类管理

左侧底部「分类管理」：

- 列出 `docs/` 下所有目录（一级 + 子级，缩进显示）
- 新建：上级目录留空 = 一级分类（会加到顶部导航）；填 `kb` = 知识库下的子分类
- 删除：整个目录连同文章一起删（能从 git 历史找回）

## 文件名规则

- 文件名自动用英文；中文标题会自动变成 `post-日期-编号`（否则网址会变成百分号编码）
- 想指定英文名，可在新建时手动填
